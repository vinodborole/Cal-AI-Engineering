# CalSoft AI Engineering Website - Site Structure & Preview

## 🎨 Visual Design Overview

### Color Palette
```
Primary Brand Colors:
├─ Primary Blue: #0066cc (Main brand identity)
├─ Primary Dark: #004c99 (Hover states, depth)
├─ Secondary Green: #00a86b (Success, growth)
└─ Accent Orange: #ff6b35 (CTAs, highlights)

Neutral Colors:
├─ Text Primary: #1a1a1a (Headings, important text)
├─ Text Secondary: #4a4a4a (Body copy)
├─ Text Light: #6b6b6b (Supporting text)
└─ Background Gray: #f8f9fa (Section backgrounds)
```

### Typography
```
Font Family: Inter (Google Fonts)
Font Weights: 300, 400, 500, 600, 700, 800

Heading Sizes:
├─ H1: 3.5rem (56px) - Hero title
├─ H2: 2.5rem (40px) - Section titles
├─ H3: 1.75rem (28px) - Card titles
├─ H4: 1.5rem (24px) - Subsections
└─ Body: 1rem (16px) - Paragraph text
```
