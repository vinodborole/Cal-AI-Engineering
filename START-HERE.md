## 🚀 Deployment Options

### Option 1: GitHub Pages (Recommended - FREE!)
**Time: 5 minutes**

1. Create GitHub repository
2. Upload all files
3. Enable GitHub Pages in Settings
4. Done! Live in 2-3 minutes

**URL:** `https://YOUR-USERNAME.github.io/calsoft-ai-engineering/`

👉 **See DEPLOYMENT.md for step-by-step guide**

### Option 2: Custom Domain
**Time: 10 minutes + DNS propagation**

Same as Option 1, plus:
- Configure custom domain in GitHub
- Update DNS records
- Wait 24-48 hours for propagation

**URL:** `https://ai-engineering.calsoftinc.com/`

### Option 3: Other Hosting
Works with any static hosting:
- Netlify (free, instant deploy)
- Vercel (free, instant deploy)
- AWS S3 + CloudFront
- Azure Static Web Apps
- Traditional web hosting

## 📝 Quick Customization Guide

### Change Colors (5 minutes)
Edit `css/style.css` lines 1-50:
```css
:root {
    --primary-color: #0066cc;    /* Your blue */
    --secondary-color: #00a86b;  /* Your green */
    --accent-color: #ff6b35;     /* Your orange */
}
```

### Update Contact Info (2 minutes)
